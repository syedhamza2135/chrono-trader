## Confirmed findings

### Medium

**M-1. A leaking agent can pass both the boundary test and non-interference by reading files.**
- Where: `tests/test_boundaries.py:22-27` (FORBIDDEN and the prefixes) and `49-60` (`agent_import_problems`).
- Evidence: five snippets get past both checks: an aliased `read_parquet` and `read_csv`, `np.fromregex`,
  `from numpy import fromregex`, and `from numpy import load as ld` (though `load` is on the forbidden list). An
  agent that reads future labels from a parquet file passes non-interference under scramble, shift and delete, while
  1,345 of its 2,467 positions differ from the honest agent's.
- Check: `scripts/skeptic_timewall/m1_boundary.py` (and `scripts/judge_timewall/check_timewall.py`).
- PLAN: L210 [digest 133], L426 [253], L609 [385]: agents import nothing but `world.view`.
- Fix: check every imported name and alias against the list, or run `decide()` in a process that cannot read
  `DATA_DIR` or `reference/`.

**M-2. When a distribution's ex-date is a label's end day, the label uses that day's closes, so the closes don't cancel.**
- Where: `data_pipeline/store.py:188`, with lines 128-129.
- Evidence: all 58 `total_return` rows in `reference/price_events.csv` fall on a label's end day, because every
  ex-date has an official open; 56 of those labels start on a member day. Where the error can be measured without a
  spin-off price, it is over 1 point on 3 of the 7 cash rows: AIV 2020-11-03 -2.09 points and NLOK 2020-02-03 -1.11
  points (member days), EQT 2018-11-13 +3.20 points. Most of the 46 spin-offs are not measured. The simulator books
  exactly the label, so the error reaches returns.
- A second effect: these labels become visible at 9:30 to 9:37 on the ex-date, before that day's close exists. A view
  at 12:00 shows all 24 in the dev years. The simulator only asks for 9:00 views (`sim/simulator.py:129`,
  `eval/leaks.py:110`), so nothing leaks today (counted as low, L-S5).
- Check: `scripts/skeptic_sim_labels/check_m1.py`, `scripts/skeptic_plan_m2/oq_exdate_label_visibility.py`.
- PLAN: L26 [digest 33, which says L27]: "the closes cancel and a wrong close can't move a label".
- Fix: give each `total_return` row an ex-date return valued at the open, and use it for the label's last piece.

**M-3. The embeddings table has no availability time and no way into `View`.** (Raised as high; the skeptic lowered
it to medium, since the table is not built yet.)
- Where: PLAN L524 [digest 322] lists `embeddings` columns with no time; `world/rules.py` and the M2 note give none.
- Evidence: the store has no embeddings table and no rule for it (`docs/digests/code_map.md`, `store_tables.md`).
  Until one exists, non-interference and the planted leaks cannot cover news features. PLAN L210 [133] already says
  agents see only `world.view`, so this is a plan gap, not a live defect.
- Check: `scripts/opus_plan_m2/`, `skeptic_plan_m2.md` section H1.
- Fix: give each embedding row its story's visible time and serve embeddings through `View`, before M2 builds the table.

**M-4. The M2 cutoff check has no outcome for "too weak to pass", so M2's done-when may be out of reach.**
- Where: M2 note L227-229; PLAN L434 [digest 258]: "done when ... the cutoff check passes (or any failing vintage is
  replaced)".
- Evidence: the note adds a "too weak" result with no next step. The skeptic also found that a failing 2015 vintage has
  no replacement, because the 2014 vintage can never pass the check.
- Check: `git show claude/awesome-panini-89f869:research/m2_kickoff.md` lines 227-229; `skeptic_plan_m2.md` M2.
- Fix: the owner decides, before the pilot, what a too-weak result means for M2's done-when.
